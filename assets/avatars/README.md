# FitAI Human Avatar Asset

Coloca aquí el modelo humano principal.

- Ruta obligatoria: assets/avatars/human-base.glb
- Formato: glTF 2.0 binario (GLB)
- Escala: cualquier unidad; FitAI normaliza automáticamente la altura al valor seleccionado.
- Recomendado: personaje humano completo, rig opcional, materiales PBR.
- Para el ciclo de vida: Morph Targets / Shape Keys con nombres compatibles con age, baby, child, young, adult, senior o equivalentes.
- Para cuerpo/rostro: Morph Targets opcionales para bodyfat, shoulderwidth, waist, facewidth y eyesize.

Si el archivo todavía no existe, FitAI conserva automáticamente el avatar procedural anterior y no rompe la página.
